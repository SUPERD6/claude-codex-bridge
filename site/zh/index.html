能做什么

两个方向都行

Claude Code 当主、Codex 干活，或者反过来；终端和桌面端都可以。

自动选模型

5 个问题打出难度 → 选智能体、模型和强度，并给出成功率；每次 ccx verify 都让它更准。

启动省钱

子智能体精简启动；一小时内同一个子会话接着用，缓存不失效。

共享记忆

开局只推对方新写的几行；还有两边都能看到的项目层。

断了能续

额度用完、崩溃或关了窗口：ccx task resume 接着原来的会话做。

有账可查

每次运行的 token 和花费，以及派出去到底省了多少的看板。

怎么工作

  1. 打分改几个文件、跨几个模块、目标清不清楚、风险、要不要新设计 → 难度 0–10。
  2. 选档成功率够高的档位里挑最便宜的；卡住了有升档路线。
  3. 运行另一个智能体在你的文件夹里后台干活；改动可以撤回，也可以放在单独的分支上。
  4. 验收你看一眼 diff，再 ccx verify——选模型会按你的工作校准。

常见问题

多一个智能体，不是更费 token 吗？

只有很小的任务会，这时 ccx 会直接让你自己做。其余的子智能体用比主智能体便宜的模型、精简启动；看板会用你自己的运行算出差多少。

我用的是订阅，不是 API，也适用吗？

适用。花费按 API 价格折算，方便比较；看板也会显示每个工具的额度用在了哪里。一边额度用完了，任务会换到另一边。

让子智能体改文件安全吗？

只能改任务所在的文件夹；每次可写运行都会拍快照，可以 ccx undo；--mode read 或 --worktree 不会动你的工作区。详见 SECURITY.zh.md。

支持哪些工具？

Claude Code 和 Codex CLI，两个方向都在真机上测过。Gemini CLI 和用 DeepSeek 的 Claude Code 已经适配，但还没真跑过。
