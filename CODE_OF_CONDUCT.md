# Code of conduct

English · 中文 below

This project is for people who build with AI coding agents. Keep it a place where anyone can ask, report and
contribute without being put down.

- Be kind and assume good intent. Criticise ideas and code, not people.
- No harassment, insults, discriminatory jokes, or unwanted personal attention — in issues, PRs, discussions or
  anywhere you represent the project.
- Respect privacy: don't post other people's personal data, and don't paste your own secrets or tokens into issues.
- Maintainers may edit or remove content and block people who break these rules.

To report a problem privately, use **GitHub → Security → Report a vulnerability** on this repository (it reaches the
maintainers only), even when the problem is about behaviour rather than code.

For situations this short page does not cover, we follow the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).

---

## 行为准则（中文）

这个项目面向用 AI 编程智能体做事的人。请让每个人都能放心提问、报告问题和贡献，不被贬低。

- 友善，先假设对方是好意。批评想法和代码，不批评人。
- 不骚扰、不辱骂、不开歧视性的玩笑、不纠缠他人——在 issue、PR、讨论区，以及任何代表本项目的场合都一样。
- 尊重隐私：不要贴别人的个人信息，也不要把自己的密钥或 token 贴进 issue。
- 维护者可以编辑或删除违反这些规则的内容，并屏蔽相关用户。

想私下报告问题，请在本仓库用 **GitHub → Security → Report a vulnerability**（只有维护者能看到），即使问题是关于人的行为而不是代码。

这页没写到的情况，按 [Contributor Covenant](https://www.contributor-covenant.org/) 的精神处理。
